# Deployment Configuration

## Project Type
Microsoft Excel Data Analytics Project

## Deployment Method
This project is delivered as an Excel workbook. It does not require a web server, application hosting, or cloud deployment.

## Setup Instructions
1. Download or obtain the Superstore dataset.
2. Open the Excel workbook.
3. Verify that the source data is available in the expected worksheet.
4. Review the product count and unique product count tables.
5. Verify the formulas and top category result.
6. Save the workbook.

## Required Files
- `Product_Count_Analysis.xlsx`
- `README.md`
- `requirements.txt`
- `deployment.md`

## Hosting
The project can be hosted in a public GitHub repository for review and portfolio purposes.

## Execution Environment
Microsoft Excel 2021 or Microsoft 365 is recommended for compatibility with the dynamic array formulas used in the unique product count analysis.

## Rollback Configuration
If an update causes an issue, restore the previous version of the Excel workbook from Git history or replace the modified file with a saved backup.

## Status
Completed – Excel-based product category analysis.

## 2. Purpose
Rollback is a recovery procedure used to restore the previous working version of the Excel workbook if any unwanted changes, formula errors, or data loss occur.

## 3. Backup Procedure
1. Save the completed workbook as `Task15_Product_Count_Analysis.xlsx`.
2. Keep a backup copy of the completed workbook.
3. Save a screenshot of the completed product count analysis.
4. Upload the approved project files to the GitHub repository.

## 4. Rollback Procedure
If an error occurs:

1. Stop editing the affected workbook.
2. Locate the backup copy of the Excel workbook.
3. Open the backup file.
4. Verify the product count table and unique product count table.
5. Check that Office Supplies is identified as the top category.
6. Save the restored workbook.
7. Replace the incorrect version in the GitHub repository if necessary.
